CST LAN Challenge - AR soldiers around a physical loot box
1. (Optional) Use your own characters:  python3 make_squad.py price.glb ghost.glb
   Models must be .glb, standing upright, facing forward. They are repeated around the ring.
   Without arguments, generic placeholder soldiers are used.
   Tune ring size / height / count at the top of make_squad.py.
2. Upload this whole folder to an HTTPS host (Netlify Drop, GitHub Pages, Cloudflare Pages).
3. python3 make_qr.py https://your-site-url/   -> qr-code.png
4. Print the QR at >=5x5 cm and attach to the physical loot box.
Android: Chrome -> Google Scene Viewer. iOS: Safari -> AR Quick Look. No app needed.
